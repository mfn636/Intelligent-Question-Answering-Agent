## 口径与限制

- 评测集由 Agent 编写，属于合成开发集；12 组场景沿用同一时序模板，未经过独立人工标注或真实用户验证。
- 每组 24 轮，在第 12、18、24 轮核对 6 个已知字段和 2 个未确认字段；包括预算更新、候选替换及区分建议与决定。
- 每个检查点包含 5 个窗口外已知字段、1 个近期已知字段和 2 个未知字段；有意测量遗忘后的恢复能力，不代表真实咨询中的问题分布。
- 评分为明确字段的规范化精确匹配；不是自由回答语义评分，也不是商品任务成功率。缺字段不会算作正确拒答。
- 答案模型只看到上下文及字段问题，不会看到标准答案。摘要器使用原有生产提示词和参数。
- 最近 10 条按消息截取，包含当前输入；生产摘要保留所有尚未压缩原文，并非每轮硬切 10 条。
- 每轮助手历史使用预写回复，不采纳检查点模型输出；这避免不同回答改变后续历史，也意味着不是自由多轮交互。
- 输入 Token 节省只比较三个检查点的回答请求；另计全部摘要输入、输出及耗时。合并总量是本次评测工作负载，不能外推为完整 24 轮实际成本。
- Token 来自 API usage，不以字符数估算；缓存单列，未按服务商单价折算费用。串行请求延迟不代表生产并发吞吐。
- 请求失败立即保存并停止；不会使用替身结果填充真实模型指标。摘要内容校验失败保留生产回退行为并单列失败数。
- 仅完整配对对话进入主表，失败对话另列；部分完成的成绩不能冒充全量结果。每项只跑一次，温度为零也不保证绝对确定性。
