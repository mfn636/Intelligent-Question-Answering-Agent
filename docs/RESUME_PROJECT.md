#### 智能问答 Agent｜基于 ReAct、Tool Calling 与 RAG 的对话系统

**技术栈：** Python、DeepSeek、Pydantic、Qdrant、BGE-M3、BM25

**面向电商领域的商品推荐、参数查询、库存查询及售后咨询真实业务场景**，构建支持多轮对话、动态工具调用和知识检索的智能问答系统，由模型根据用户需求选择工具，并结合查询结果生成回答。

- **Agent 执行核心：** 实现 ReAct 循环，完成模型决策、工具执行、结果回填与最终回答的完整链路；支持参数解析失败反馈、工具异常处理及执行步数限制，将会话管理与执行算法解耦。
- **工具接入层：** 设计统一工具契约并实现 `LocalProvider`，从同一份工具定义生成模型侧工具说明与本地函数查找表；使用同一个 Pydantic 参数模型生成 JSON Schema 并校验调用参数，校验通过后执行函数，统一返回 JSON 结果。
- **业务工具：** 接入商品搜索、商品详情、库存查询和知识检索四类工具，知识库覆盖 FAQ、指南、政策和帮助文档；通过依赖注入绑定业务数据与检索服务，支持类别、预算、品牌等条件筛选，为模型回答提供业务依据。
- **工具容错：**  Pydantic 校验**区分模型参数错误与本地执行故障**，参数未通过 Pydantic 校验时跳过执行，回填字段错误供模型有限次数修正；针对可安全重复执行的查询，对临时依赖故障采用带抖动的指数退避重试，限制次数与总耗时；依赖持续异常时触发熔断，冷却后通过少量探测恢复，并阻止 ReAct 重复执行已耗尽预算的失败调用。
- **混合检索与重排序：** 基于 Qdrant、BGE-M3 与 BM25 构建向量和关键词双路召回，通过 RRF 融合排名并对 Top-20 候选片段重排序；在自建电商检索集（270 条查询）与 SciFact 公开基准（300 条查询）上开展纯向量、混合检索、混合加重排三组消融评测。相比纯向量，混合加重排将电商集 Hit@1 从 79.6% 提升至 86.7%、Hit@5 从 97.8% 提升至 99.6%，SciFact nDCG@10、Recall@10 分别提升 8.3、7.2 个百分点。
- **会话记忆优化：** 采用“**增量摘要＋近期原文**”组织上下文，超过阈值后按完整问答压缩历史，将旧摘要与新增历史融合；摘要失败时保留原文，支持跨轮需求延续。
- **工程与可观测性：** 集中管理共享依赖及资源生命周期，分离用户回复、运行状态与工具轨迹，记录工具调用参数和结果，并统计每轮模型调用次数、Token 用量及请求延迟。
